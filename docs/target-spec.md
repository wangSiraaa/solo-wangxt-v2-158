# 套准色标格式规范 v1（REG-TARGET/1）

本系统只识别本规范定义的合成色标。检测与夹具生成共用 `backend/app/cv/spec.py`。

## 设计目标

把**纸张级变换**（扫描旋转、DPI/尺度变化、平移）与**色版级位移**解耦：

- 校准要素全部用 **K（黑）油墨**印刷：色版整体平移时，校准尺随之一起移动，但校准尺
  自身形状不变，所以从校准尺估出的旋转角和尺度不依赖任何色版偏移。
- 每个色版只有一个小圆点；圆点在校准坐标系中的位置偏差即该色版偏移。

## 几何定义（印刷坐标系，单位 mm，100% 尺度、零旋转）

```
                 ■P0 (3.0, 3.0)  K填充角点
  +-----------------------------------+   y=5
  |  ●dC (-3.5,-3.5)                  |
  |                                   |
  |                                   |
  |      ●dM (-1.75,-1.75)            |
  |                                   |
  |                 ●dY (0,0)         |
  |                                   |
  |                      ●dK0(1.75,1.75)
  |                                   |
  |             ●dK1 (3.5,3.5)        |
  |                              ■P1 |   P1 (-3.0,-3.0) K填充角点
  +-----------------------------------+   y=-5
 x=-5                              x=5
```

- **校准方框**：边长 `FRAME_SIDE = 10 mm` 的 K 描边方框，线宽 `FRAME_LINEWIDTH = 0.30 mm`。
  方框中心即色标原点 O。
- **非对称角点（定方向）**：两个 K 填充方块，边长 `PIP_SIDE = 0.9 mm`，
  其内边相对方框角内缩 `PIP_INSET = 0.55 mm`：
  - `P0 = (+3.0, +3.0)` mm（落在 +x/+y 象限）
  - `P1 = (-3.0, -3.0)` mm（落在 -x/-y 象限）
  两点不对称且不同距，可唯一确定四方向（避免 180°/镜像歧义）。
- **色版圆点**：直径 `DOT_DIAMETER = 0.55 mm`，各版标称印刷坐标（mm）：

| 色版 | 键 | 标称位置 (x, y) |
|---|---|---|
| 青 | `C` | (-3.50, -3.50) |
| 品红 | `M` | (-1.75, -1.75) |
| 黄 | `Y` | ( 0.00,  0.00) |
| 黑 | `K` | (+1.75, +1.75) （控制点 dK0） |
| 黑（冗余） | `K1` | (+3.50, +3.50) （控制点 dK1，用于验证；K 版两点应一致） |

理想状态下各色版偏移为 0。若 C 版在印版上平移 (δx, δy)，则 dC 的实测印刷坐标为
标称位置 + (δx, δy)。**K 是参照版：δK 恒报 0**（用 dK0/dK1 两个点的一致性做质量自检）。

## 扫描图模型

扫描像素 = 扫描仿射变换（绕页面中心旋转 θ、各向同性尺度 s = dpi/200、平移 t）
作用于理想印刷坐标（200 DPI 基准）后光栅化，并叠加：

- 高斯模糊、传感器噪声、JPEG 压缩；
- 可选缺陷：缺色（整版不印）、污点（随机暗/彩色颗粒）、标记残缺（局部遮挡）。

## 检测约定

- 校准：K 掩膜 → 连通域 → 大轮廓拟合四角（minAreaRect）→ 两个 pip 质心确定方向符号；
  从方框四条边估 θ 与 s，θ/s 有独立置信度与残差（单位 mm）。
- 色版点：Lab 空间按油墨参考色近邻分类 + 连通域圆度过滤；找不到唯一圆点时返回
  多个候选（质心、面积、圆度、分类距离），结果置 `ambiguous`。
- 输出单位：偏移与不确定度一律 **微米 (µm)**，1 位小数；不确定度来自亚像素质心
  方差、校准残差和候选散布，不会给虚假精度。
